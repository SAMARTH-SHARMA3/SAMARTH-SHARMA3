<table align="center">

<td width="33%" valign="top">

### 🔬 Compiler-Aware Performance Modelling of NVDLA
*Postgraduate Diploma dissertation · Mar – Aug 2025*

Compared NVIDIA NVDLA's native compiler with ONNC on LeNet-5, AlexNet and SqueezeNet. ONNC cut memory footprint by **12–22%** and instruction counts by up to **27%** via operator fusion and buffer reuse.

`Python` `ONNC` `Caffe` `NVDLA` `ONNX`

</td>

*Jan – Mar 2025*

Built SVM and multi-head attention BiLSTM models for semantic relation classification, reaching up to **82.9% F1** with TF-IDF, POS tagging, dependency parsing and GloVe embeddings.

`PyTorch` `scikit-learn` `spaCy` `Gensim`
